# 产品范围与验收基线

## 目标

构建校园马拉松赛事从赛事发布、用户报名、缴费、成绩录入到证书发放的完整闭环，并为自动化测试提供稳定、可重复的业务状态。

## 用户端

### 首页与搜索

- 推荐活动展示标题、状态、时间、地点和费用。
- 支持关键词搜索。
- 支持全部、报名中、未开始和已结束筛选。

验收标准：

- 已下架活动不能出现在用户端。
- 搜索无结果时返回空列表，不返回服务器错误。
- 活动状态以服务器时间为准。

### 报名

报名状态：

```text
WAIT_PAYMENT -> REGISTERED -> COMPLETED
```

验收标准：

- 报名窗口外禁止报名。
- 同一用户不能重复报名同一赛事。
- 名额已满时禁止创建报名。
- 只有报名本人可以支付自己的待缴费记录。
- 未缴费状态不计入正式报名。

### 评价

评价状态：

```text
PENDING -> APPROVED
PENDING -> REJECTED
```

验收标准：

- 只有已报名用户可以提交评价。
- 新评价默认待审核，不能立即出现在公开列表。
- 用户只能删除自己的评价。
- 管理员可以通过或驳回待审核评价。

### 证书

证书状态：

```text
UNISSUED -> ISSUED
```

验收标准：

- 只有已完赛用户可以生成证书。
- 未颁发证书不能出现在用户的已颁发证书列表。
- 证书编号全局唯一。

## 管理员端

- 使用独立管理员角色访问。
- 赛事、报名、成绩、证书、学校和评价管理均需要鉴权。
- 管理员可以检索和分页查看业务数据。
- 普通用户访问管理员接口时返回 403。

## 测试优先级

1. 鉴权与越权访问。
2. 报名窗口、重复报名、名额与支付状态。
3. 评价审核可见性和所有权。
4. 成绩到证书的状态约束。
5. 管理端检索、分页和异常输入。
